# 萊爾富門市據點資訊抓取指南

## 🎯 目標

抓取**全台灣 17 個縣市**的萊爾富便利商店門市據點資訊

## 📋 覆蓋範圍

- **直轄市**：台北市、新北市、桃園市、台中市、台南市、高雄市
- **省轄市**：基隆市、新竹市、嘉義市
- **縣**：宜蘭縣、新竹縣、苗栗縣、彰化縣、南投縣、雲林縣、嘉義縣、屏東縣

## 🚀 快速開始

### 方法 1：使用最強化版本（推薦）

```bash
perl hilife_v3.pl
```

### 方法 2：使用階層式查詢版本

```bash
perl hilife_v2.pl
```

## 📊 預期結果

### 個別城市檔案

```
csv/台北.csv
csv/新北.csv
csv/桃園.csv
csv/台中.csv
csv/台南.csv
csv/高雄.csv
... 等 17 個檔案
```

### 合併後的完整資料

```bash
perl merge.pl
```

產生：`Shop_list.csv`

## 📝 資料格式

```csv
name,phone,city,region,detailed_address,latitude,longitude
HiLife 中正門市,02-2345-6789,台北市,中正區,重慶南路一段100號,,
```

## ⚡ 執行特色

- **反反爬蟲**：完整瀏覽器模擬
- **階層式查詢**：縣市 → 地區 → 門市
- **智能延遲**：避免被封鎖（地區間 3-5 秒，城市間 8-12 秒）
- **錯誤重試**：多種訪問策略
- **UTF-8 編碼**：完整中文支援

## 🎉 完成後你將獲得

- **全台萊爾富門市清單**
- **包含門市名稱、電話、地址**
- **按縣市分類的 CSV 檔案**
- **統一的合併檔案**
