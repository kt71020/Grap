# 悟饕池上飯包門市爬蟲

## 網站資訊

- 目標網站：https://www.wu-tau.com/store.php
- 品牌名稱：悟饕池上飯包
- 資料來源：官方門市查詢頁面

## 檔案架構

### 檔案結構設計

1. **`Shop_info.csv`** - 商店基本資訊與商品目錄（靜態資料）
2. **`Shop_list.csv`** - 爬蟲產生的門市列表（動態資料）
3. **`Shop_menu.csv`** - 完整合併檔案（基本資訊 + 門市列表）

## 檔案說明

### get_city.pl

- 用途：分析網站結構，取得城市代碼對照表
- 功能：列印城市映射表，確認抓取範圍

### wutau.pl

- 用途：主要爬蟲程式
- 功能：
  - 爬取各城市的門市資訊
  - 處理分頁資料
  - 輸出個別城市的 CSV 檔案至 csv/ 目錄
  - 自動處理電話號碼格式化
  - 生成完整的 `Shop_list.csv` 門市列表

### merge.pl

- 用途：合併商店資訊與門市列表
- 功能：
  - 合併 `Shop_info.csv`（商店基本資訊）和 `Shop_list.csv`（門市列表）
  - 產生統一的 `Shop_menu.csv` 完整檔案
  - 顯示各城市門市統計
  - 自動檢查來源檔案存在性

### debug.pl

- 用途：調試和測試工具
- 功能：診斷網站結構變化和資料抓取問題

## 資料格式

### Shop_info.csv 格式

```
---,分隔線,商店資訊---
name,集山實業股份有限公司
city,宜蘭縣
region,五結鄉
detailed_address,五濱路一段18號
phone,03-990-3366
introduction,飯包是給外人吃的，一定要用心做...
...
```

### Shop_list.csv 格式

```
name,phone,city,region,detailed_address,latitude,longitude
悟饕池上飯包 台北東湖店,02-2633-8976,台北市,內湖區,東湖路113巷60號1樓,,
...
```

### 欄位說明

- **name**: 門市名稱（格式：悟饕池上飯包 + 原始店名）
- **phone**: 電話號碼（已格式化為 XX-XXXX-XXXX 或 XX-XXXXXXX）
- **city**: 城市名稱
- **region**: 地區名稱
- **detailed_address**: 詳細地址（已移除城市和地區前綴）
- **latitude**: 緯度（此網站未提供，為空值，可由後端程式補充）
- **longitude**: 經度（此網站未提供，為空值，可由後端程式補充）

## 使用方法

### 1. 執行爬蟲

```bash
perl wutau.pl
```

### 2. 合併檔案

```bash
perl merge.pl
```

### 3. 檢視城市對照表

```bash
perl get_city.pl
```

### 4. 調試模式

```bash
perl debug.pl
```

## 注意事項

1. **網站限制**: 程式包含適當的延遲機制避免被封鎖
2. **編碼**: 所有檔案使用 UTF-8 編碼
3. **錯誤處理**: 包含網路錯誤和資料異常的處理
4. **測試模式**: 可在 wutau.pl 中啟用測試模式，只抓取部分城市
5. **經緯度**: 網站未提供經緯度資料，需由後端程式另行獲取
