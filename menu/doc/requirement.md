# 商店目錄圖諞轉 CSN

將拍攝的商店菜單目錄取得圖中文字轉成指定格式 CSV2 檔案

## 資料來源

### Flutter APP

APP 提供拍攝菜單的功能讓使用者拍攝圖片，並將圖片存至 Google Storage。

#### 技術瓶頸

1. 如何將圖片扁平化減少光線影響
2. 圖片文字對比提高影像辨識能力

### 本地端檔案

#### 技術瓶頸

1. 如何將圖片扁平化減少光線影響
2. 圖片文字對比提高影像辨識能力
3. 預先處理

## 影像文字辨識

### 處理平台

### Fluttter

我要在 Flutter APP 中提供拍照功能，拍攝的題材為商店菜單，提供給後端進行內容與文字辨識。APP 拍照功能希望能達到：

1. 手機照相透視變形，表格偵測失準，將歪斜的表格拉正。
2. 使用掃描圖片提高解析度與對比。

### Numu 菜單辨識

由影像文字辨識索取得的文字，由 AI 辨識菜單的功能取得菜單的資訊。

#### Google Document AI Form Parser

帶你把菜單影像（JPG／PDF）丟進 Google Document AI – Form Parser，並拿回結構化欄位、表格與座標資訊。

#### 回傳 JSON 結構重點

| 欄位                                            | 說明                                                        |
| ----------------------------------------------- | ----------------------------------------------------------- |
| `document.text`                                 | 全文文字（供錨點對應）                                      |
| `document.pages[n].tables`                      | 表格陣列；含 `header_rows`、`body_rows` 與每格 bounding box |
| `document.pages[n].form_fields`                 | 鍵值對清單（key & value 皆帶 `text_anchor`）                |
| `document.pages[n].paragraphs / lines / tokens` | OCR 粒度更細，可自訂格式重組                                |

將 Document 物件轉成 pandas.DataFrame

#### 菜單辨識要取得資料

- 基本資料
  1. 公司名稱:商店名稱
  2. 城市：例如,台北市、基隆市
  3. 鄉鎮市區：例如,士林區、礁溪鄉
  4. 詳細地址：路名與其他地址資料
  5. 電話：訂購電話
  6. 介紹:商店介紹
  7. 訂購備註:訂購須知
- 商品資料
  1. 商品名稱
  2. 商品價格
- 商品分類
  菜單中將商品分類的類別

## CSV 檔案格式

```csv
---,分隔線,商店資訊---
公司名稱:商店名稱
城市：例如,台北市、基隆市
鄉鎮市區：例如,士林區、礁溪鄉
詳細地址：路名與其他地址資料
電話：訂購電話
介紹:商店介紹
訂購備註:訂購須知

---,分隔線,商品分類代碼,---
商品分類編號,商品分類名稱


---,分隔線,共用選項代碼,---
選項編號,選項名稱,必選項目

---,分隔線,共用選項價格代碼,---
選項編號,名稱,價格


---,分隔線,商品資料---
名稱,價格


```
